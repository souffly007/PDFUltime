# PDF Ultime

Application Android libre et moderne pour lire et gérer ses documents PDF.

## Première version

- Lecture PDF avec navigation horizontale
- Zoom avant et arrière
- Ouverture depuis le stockage Android ou le menu Partager
- Fusion de plusieurs fichiers PDF
- Création et sauvegarde d’une signature manuscrite
- Ajout de texte dans un PDF
- Navigation par flèches au-dessus de la barre Android
- Thèmes clair, sombre et CyanogenMod
- Section À propos
- Navigation par flèches en bas du lecteur PDF
- Interface adaptative avec logo Zen Projects en pied de page
- Interface claire, locale et sans compte obligatoire

## Importation dans Android Studio

1. Décompressez l’archive.
2. Ouvrez le dossier `PDFUltime` dans Android Studio.
3. Attendez la synchronisation Gradle.
4. Connectez votre smartphone avec le débogage USB activé.
5. Lancez l’application avec **Run**.
